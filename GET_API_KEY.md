# Как получить Anthropic API ключ

Для работы генератора контента необходим API ключ от Anthropic Claude.

## Шаг 1: Создайте аккаунт

1. Перейдите на https://console.anthropic.com/
2. Нажмите **Sign Up** (если у вас нет аккаунта)
3. Заполните регистрационную форму:
   - Email адрес
   - Пароль
   - Подтвердите email

## Шаг 2: Добавьте платежный метод

⚠️ **Важно**: Claude API платный, но очень доступный:
- Первые $5 кредита бесплатно (для новых аккаунтов)
- Claude 3.5 Sonnet стоит примерно $3 за миллион токенов input / $15 за миллион токенов output
- **Один пост обычно стоит $0.01-0.03** (очень дешево!)
- 100 постов ≈ $1-3

Добавьте кредитную карту в разделе **Billing**.

## Шаг 3: Создайте API ключ

1. В консоли Anthropic перейдите в раздел **API Keys**
2. Нажмите **Create Key**
3. Дайте ключу имя (например, "Module Masters Generator")
4. Скопируйте ключ (он будет показан только один раз!)

Ключ выглядит примерно так:
```
sk-ant-api03-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

## Шаг 4: Добавьте ключ в .env

1. Откройте файл `backend/.env` в текстовом редакторе
2. Найдите строку:
   ```
   ANTHROPIC_API_KEY=sk-ant-api03-YOUR_API_KEY_HERE
   ```
3. Замените `YOUR_API_KEY_HERE` на ваш настоящий ключ:
   ```
   ANTHROPIC_API_KEY=sk-ant-api03-ВАШТКЛЮЧ
   ```
4. Сохраните файл

## Шаг 5: Готово!

Теперь вы можете запустить приложение:
```bash
./start-backend.sh   # В одном терминале
./start-frontend.sh  # В другом терминале
```

## Альтернативный способ (через переменные окружения)

Вместо редактирования .env файла, можно экспортировать ключ:

**macOS/Linux:**
```bash
export ANTHROPIC_API_KEY="sk-ant-api03-ВАШТКЛЮЧ"
./start-backend.sh
```

**Windows (PowerShell):**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-api03-ВАШТКЛЮЧ"
python backend/app.py
```

## Проверка API ключа

Чтобы убедиться что ключ работает:

```bash
cd backend
source venv/bin/activate
python -c "
import os
from anthropic import Anthropic
client = Anthropic(api_key=os.getenv('ANTHROPIC_API_KEY'))
message = client.messages.create(
    model='claude-3-5-sonnet-20241022',
    max_tokens=50,
    messages=[{'role': 'user', 'content': 'Hello!'}]
)
print('✅ API key works!')
print(message.content[0].text)
"
```

Если увидите приветствие от Claude - всё работает!

## Часто задаваемые вопросы

### Сколько это стоит?

Типичное использование:
- **1 пост** = $0.01-0.03 (1-3 цента)
- **100 постов в месяц** = $1-3
- **1000 постов в месяц** = $10-30

Это намного дешевле, чем платить копирайтеру!

### Что если у меня закончатся деньги?

API просто перестанет работать. Добавьте баланс в консоли Anthropic.

### Могу ли я установить лимит расходов?

Да! В консоли Anthropic в разделе **Billing** можно установить:
- Месячный лимит расходов
- Уведомления при достижении порога

Рекомендуется установить лимит $10-20 для начала.

### Есть ли бесплатные альтернативы?

Вы можете использовать другие LLM API:
- OpenAI GPT-4 (похожие цены)
- Google Gemini (бесплатный tier существует)
- Модифицируйте `content_generator.py` для работы с другим API

### Безопасно ли хранить ключ в .env?

Да, если:
- ✅ `.env` добавлен в `.gitignore` (уже добавлен)
- ✅ Вы не публикуете этот файл
- ✅ Не коммитите его в Git

**Никогда не публикуйте свой API ключ в открытом доступе!**

## Поддержка

Если возникли проблемы:
- Проверьте что ключ скопирован полностью
- Убедитесь что нет лишних пробелов
- Проверьте баланс в консоли Anthropic
- Посмотрите логи backend сервера для деталей ошибок
